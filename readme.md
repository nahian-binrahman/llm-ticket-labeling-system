## 🚀 Overview

Manual customer support ticket labeling is:

- ⏳ Time-consuming
- 💸 Costly
- 📉 Hard to scale

This project solves these problems using a **smart AI-powered pipeline**:

> 🤖 Large Language Models (LLMs) + 👨‍💻 Human-in-the-Loop = ⚡ Scalable + 🎯 Accurate labeling

---

## 🎯 Key Features

✨ End-to-end automated labeling system:

- 🤖 **LLM-powered ticket classification**
- 📊 **Confidence scoring for predictions**
- ⚠️ **Low-confidence detection**
- 👨‍💻 **Human review workflow**
- 📈 **Performance evaluation**
- 🧪 **Prompt optimization loop**
- 🧹 **Clean dataset generation**

## 🧩 Labels Generated

Each ticket is enriched with multiple structured labels to better understand customer issues and improve downstream analytics.

---

### 🏷️ Label Categories

| Category        | Description | Example Values |
|----------------|------------|----------------|
| **Sentiment**  | Overall tone of the ticket | positive, negative, neutral, mixed |
| **Topic**      | Main subject of the issue | technical_issue, billing_issue, refund |
| **Intent**     | What the user wants to achieve | complaint, technical_help, refund_request |
| **Emotion**    | Emotional state of the user | frustrated, confused, angry |
| **Confidence** | Model’s certainty in prediction | 0.0 – 1.0 |
| **Reason**     | Explanation generated by LLM | "User reports repeated login failure" |

## 🚀 How to Run

Follow these steps to run the project:

###

```bash
1️⃣ Install Dependencies
pip install -r requirements.txt
2️⃣ Run LLM Labeling
python src/llm_labeler.py
3️⃣ Filter Low-Confidence Predictions
python src/review_filter.py
4️⃣ Start Human Review App
streamlit run app/review_app.py
5️⃣ Evaluate Performance
python src/evaluate.py
6️⃣ Create Final Dataset
python src/create_final_dataset.py
7️⃣ Launch Dashboard
streamlit run app/dashboard.py
```
